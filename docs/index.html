Autonomous Tool Synthesis Loop

When you ask PerSona to perform dynamic calculations, queries, or automations, the agent writes a JavaScript skill script on the fly, registers it into the local Skill Registry, and executes it securely.

skills/calculate_risk_matrix/handler.js Auto-Synthesized 
async function execute(args) {
  const { severity, likelihood } = args;
  const score = severity * likelihood;
  return {
    riskLevel: score > 15 ? "CRITICAL" : score > 8 ? "HIGH" : "MODERATE",
    calculatedScore: score,
    mitigationPriority: score > 15 ? "P0" : "P1"
  };
}
Why PerSona

Engineered for Complete Data Sovereignty

Zero telemetry, zero external API keys required, zero cloud subscriptions. Everything runs locally on your silicon.

100% Offline & Air-Gapped

All models run via local Ollama instances (Llama 3.2, DeepSeek, Mistral, Qwen). Your documents, embeddings, and chat history never leave your machine.

Embedded LanceDB Vector Engine

Sub-millisecond cosine and semantic vector similarity search powered by Rust bindings directly against embedded disk storage. No external vector service required.

Live Folder Watcher & Sync

Point PerSona to any folder on your computer. Whenever files are added or modified, PerSona detects changes and updates your knowledge base in the background.

Local LAN Host Server

Toggle the built-in Axum REST server to securely share your knowledge base with other devices, mobile phones, or laptops on your home or office network.

Self-Synthesizing Skill Registry

PerSona's agent loop can write, save, and execute custom JavaScript tools to solve specialized calculation and transformation tasks automatically.

Tauri v2 Desktop Architecture

Minimal memory footprint, instant startup, global hotkey summoning (⌥ Option + Space), and native macOS/Windows/Linux platform integration.

Quick Start

Get Running in 3 Easy Steps

Run PerSona completely on your own machine in minutes.

1

Install Ollama & Pull Model

Download Ollama and pull your preferred local model:

ollama pull llama3.2
2

Clone the Repository

Clone the project and install the dependencies:

git clone https://github.com/MayankGit-hu/PerSona.git && cd PerSona && npm install
3

Launch PerSona

Start the desktop app in development mode or build the production release:

npm run tauri dev
